## Repeater Directory Entry (W0SRC, fictional)

| Parameter | Value |
|-----------|-------|
| Output (you listen) | 146.940 MHz |
| Input (you transmit) | 146.340 MHz |
| Offset | -600 kHz |
| Access tone (CTCSS) | 100.0 Hz |
| Mode | FM |
| Notes | Open to licensed amateurs; identify every ten minutes |

The radio last booted with a transmit tone of 123.0 Hz. The entry is an
authored local fixture, not a universal default.

---

## Club DMR Channel Card

| Parameter | Value |
|-----------|-------|
| Color code | 1 |
| Time slot | 2 |
| Talkgroup | 31337 "Club Tech Net" |

The DMR (digital mobile radio) handheld is a separate club loaner. The analog
radio does not gain DMR through a menu. A code plug is the saved file that
holds channels like this one; it is a different thing from an access tone.

## Privileges Relied On

| Rule | Use here |
|------|----------|
| 47 CFR 97.301(e) | Technician privileges include 144-148 MHz |
| 47 CFR 97.305 | FM voice and data emissions are authorized there |
| 47 CFR 97.119 | Identify with KF0SRT at the end of the contact and every ten minutes |

<Aside type="note">
Transmit tone and receive tone squelch are separate settings. A courtesy tone
from the repeater is not a reply from another operator. All stations here are
simulation fixtures.
</Aside>

## Operating Checklist

- [ ] Output, input, offset and tone pulled from the entry
- [ ] Radio's actual transmit frequency compared with the computed input
- [ ] Working settings left alone while the rest is checked
- [ ] Channel stored as a named memory, recalled, values confirmed
- [ ] Identified call made, then a pause for a real reply
- [ ] DMR card loaded with color code, time slot and talkgroup all matching

## End of Briefing

The repeater sits behind a few small numbers. Check each against the card
before blaming the hardware.
