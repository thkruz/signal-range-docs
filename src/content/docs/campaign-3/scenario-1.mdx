## Training Signal Card

| Parameter | Value |
|-----------|-------|
| Frequency | 146.550 MHz |
| Mode | FM (narrowband voice) |
| Receive filter preset | 15 kHz |
| Content | One short spoken message |

<Aside type="caution">
The 146.550 MHz training transmission and every station in this campaign are
simulation fixtures, not a claim that any real channel carries them. Check a
current band plan and your own license before operating on a real frequency.
</Aside>

## Privilege Notes

Receiving needs no license. Transmitting does: 144-148 MHz is open to
Technician licensees under 47 CFR 97.301(e), and the emission types allowed
there are listed in 97.305. You do not transmit in this session.

---

## Bench Checklist

- [ ] Antenna, feed line, receiver, audio destination: every connection identified
- [ ] Connector fully seated, receiver unplugged from power while you handle it
- [ ] Frequency, mode and filter set to the card values
- [ ] Volume and squelch handled as two separate controls
- [ ] Filter compared against a narrower one, then restored
- [ ] Message recorded as actually received

<Aside type="note">
More gain is not a better signal. Judge by whether the message is intelligible.
</Aside>
