## Antenna Fixtures

| Item | Value |
|------|-------|
| Target frequency | 146.550 MHz (inside the 144-148 MHz band) |
| Length approximation | Total length in meters = 143 / f (MHz), a starting estimate only |
| Reference station | Vertically polarized |
| Site hazards on the diagram | Overhead service wire, unstable mounting, occupied antenna space |
| Exposure worksheet inputs | Power, antenna gain, frequency, duty cycle, distance, public or controlled area |

The formula's result is the total length, not the length of each side.

All stations here are simulation fixtures.

<Aside type="caution">
No tower climbing and no work near overhead wires. Adjust the elements with the
analyzer connected and the transmitter off. An acceptable match reading says
nothing about exposure compliance, and it is only part of the evidence for
antenna performance.
</Aside>

## Build Checklist

- [ ] Starting length calculated from the formula
- [ ] Site rejected or accepted against the hazards on the diagram
- [ ] Elements cut slightly long, feed line connected, strain relief fitted
- [ ] Sweep read; both elements shortened by equal small amounts
- [ ] Orientation compared with the vertically polarized reference
- [ ] Worksheet filled in and installation checked against it
- [ ] Before-and-after reports saved as the baseline
