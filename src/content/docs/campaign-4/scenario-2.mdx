## Fault Response Card

How we work a transmit-chain alarm on this trailer. Read the panel first; the alarm tells you which module, and which module tells you what to do.

| What the panel shows | What it is | Response |
|----------------------|------------|----------|
| Exciter FAULT lit; HPA nominal; BUC ref locked | Exciter trip (latched) | Leave the HPA enabled. Select the other string, key it, confirm DENIED on assessment. |
| Exciter FAULT lit on both strings | Out of spares | Select the string that has had time to cool. FAULT RESET with it un-keyed, wait for the light to clear, key it. |
| HPA alarm (over-temp, overdrive, no output) | Amplifier trouble | Disable HPA, un-key the exciter, call Delgado. Do not attempt a restart from console. |
| BUC reference unlock | Timing | Un-key, power-cycle BUC, re-verify lock before re-keying. |
| Assessment drops to DEGRADED, no alarms | Pointing or power | Check the jam antenna on the ACU before touching the chain. |

<Aside type="caution">
The amplifier is shared. Disabling the HPA to change exciters drops the effect for the whole re-enable sequence, and the assessment clock does not stop for you. Change strings behind an enabled amplifier.
</Aside>

<Aside type="danger">
Whatever you do to recover a string, the waveform stays at 8,125 MHz and 5 MHz wide. Widening or retuning toward 8,175 MHz to "make up for lost time" is the one recovery that ends the tasking outright.
</Aside>

## Escalation Guidelines

### Handle Yourself

- Exciter trips and fault resets
- String changes behind the shared amplifier
- Monitor aperture pointing
- Assessment lapses with a clear cause

### Call Delgado (channel 2)

- Any HPA alarm
- A string that will not clear on reset
- Anything that needs a hand on the rack

### Call RAMPART

- Loss of effect you cannot restore within three minutes
- Any protected-band question, before you radiate, not after
