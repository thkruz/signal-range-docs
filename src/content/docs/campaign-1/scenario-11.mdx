## Planned Handover Procedure (SOP-MX-002)

This SOP differs from the weather-handover procedure (SOP-WX-003) used in S3. There is no time pressure, no need to enable the source-station feed heater, and the source-station antenna goes to maintenance position rather than stow. Read the checklists carefully - the muscle memory from weather handovers will get the sequence almost right but not exactly.

### Pre-Handover: Source Station Baseline

- [ ] VT-01 dashboard: no active alarms
- [ ] VT-01 antenna: locked on TIDEMARK-1
- [ ] VT-01 traffic ownership: confirmed

### Receive-Side Verification (Maine)

- [ ] Antenna locked on TIDEMARK-1 (program-track)
- [ ] TIDEMARK-1 beacon visible at 1,074.5 MHz IF
- [ ] RX modem locked
- [ ] C/N ≥ 10 dB

### Transmit-Side Staging (Maine)

- [ ] TX modem: transmitting (into the muted BUC)
- [ ] BUC: still muted
- [ ] HPA: still disabled

<Aside type="caution">
Never bring the receiving station's RF up by hand while the source is still
radiating. Two uplinks on the same transponder is dual illumination - an
immediate, customer-visible violation. The traffic transfer stands VT-01 down
and brings ME-02 up in one coordinated swap; your job is to have Maine staged
so that swap lands on a ready chain.
</Aside>

### Traffic Transfer

- [ ] Open TIDEMARK-1 satellite dashboard
- [ ] Execute transfer: VT-01 → ME-02
- [ ] Verify ME-02 is the new traffic owner
- [ ] Service continuity confirmed (zero packet loss target)

### Post-Handover: Safe Vermont for Crew

- [ ] Return to VT-01 station view
- [ ] HPA: disabled
- [ ] BUC: muted
- [ ] Antenna tracking mode: Maintenance
- [ ] Antenna position: El 5° reached

## Crew Hand-Off Reference

Before Pete and his crew approach the feed assembly, walk the floor and confirm the station is safe:

| Check | Pass Criteria |
|-------|---------------|
| HPA output | Disabled - no green output indicator |
| BUC | Muted - no transmit indicator |
| Antenna position | El 5°, dish accessible from the catwalk |
| RF energy on feed | None - no transmit chain active |

A maintenance-position dish (5°) is different from a stow-position dish (90°). Stow protects against weather; maintenance lets a human work the feed. Confirm the antenna is at maintenance, not stow.
