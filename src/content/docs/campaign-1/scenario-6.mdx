## Background: Inclined Orbit Satellites

### Why Satellites Drift

Geostationary satellites maintain their position through active station-keeping. Small thrusters fire periodically to counteract gravitational perturbations from the Sun, Moon, and Earth's equatorial bulge. This keeps the satellite in a fixed position relative to ground stations.

Station-keeping consumes fuel. When a satellite's fuel reserves run low, operators face a choice:
- **Decommission**: End operations and move to graveyard orbit
- **Extend life**: Stop station-keeping and operate with an inclined orbit

Many operators choose extended operations. The satellite still functions - it just moves.

### The Figure-8 Pattern

When north-south station-keeping stops, the satellite's orbital plane begins to tilt relative to the equator. From a ground station's perspective, the satellite appears to drift north and south over a 24-hour period, tracing a figure-8 pattern in the sky.

**The Motion:**
- **Daily cycle**: North-south excursion repeats every 24 hours
- **Inclination growth**: Typically 0.7-0.9 degrees per year without correction
- **Position variation**: A 5-degree inclined orbit creates significant pointing error

For AURORA-7, years without station-keeping have resulted in substantial orbital inclination. The apparent motion is enough that program-track predictions - based on a fixed geostationary position - are too inaccurate for reliable operations.

### Station-Keeping Economics

Fuel represents mission life. The decision to stop station-keeping extends revenue-generating operations:

| Fuel Status | Operator Decision | Ground Station Impact |
|-------------|------------------|----------------------|
| Normal reserves | Full station-keeping | Program-track works fine |
| Low reserves | Reduced station-keeping | Minor pointing drift |
| Critical reserves | Stop N-S station-keeping | Inclined orbit, requires step-track |
| Depleted | End of mission | Satellite decommissioned |

Many commercial satellites operate in inclined orbit mode for years beyond their original design life, continuing to generate revenue while requiring more sophisticated ground tracking.

## Tracking Modes Explained

### Program-Track

Program-track uses Two-Line Element (TLE) data to predict satellite position. The antenna control unit calculates where the satellite should be at any moment and points accordingly.

**How It Works:**
```
1. Load TLE orbital elements for target satellite
2. Propagate orbit to current time
3. Calculate azimuth and elevation
4. Point antenna to computed position
5. Repeat continuously
```

**Advantages:**
- No signal required - can point before acquiring
- Works for any satellite with published TLEs
- Simple implementation

**Limitations:**
- Accuracy depends on TLE freshness and orbit stability
- Geostationary assumptions break down for inclined orbits
- No feedback loop to correct pointing errors

**Best For:** Acquisition of geostationary satellites, initial pointing for any satellite.

### Step-Track

Step-track actively optimizes antenna pointing by measuring beacon signal strength. The algorithm makes small adjustments to find and maintain the peak signal level.

**How It Works:**
```
1. Start from approximate position (from program-track)
2. Measure beacon C/N ratio
3. Make small step in azimuth
4. If C/N improved, continue that direction
5. If C/N degraded, reverse direction
6. Repeat for elevation
7. Continuously hunt for peak signal
```

**Advantages:**
- Self-correcting - follows the actual satellite position
- Compensates for orbital drift, atmospheric refraction, antenna mechanical errors
- Achieves maximum signal through continuous optimization

**Limitations:**
- Requires beacon signal for tracking
- Needs beacon receiver tuned to correct frequency
- Slight signal variation during optimization steps

**Best For:** Inclined orbit satellites, maximizing signal quality, long-term tracking.

### The Handoff Pattern

Professional operations typically use both modes:

<Steps>

1. **Initial Acquisition**: Program-track points antenna to predicted position

2. **Beacon Detection**: Verify beacon signal is visible on spectrum analyzer

3. **Mode Transition**: Switch to step-track once beacon is detected

4. **Optimization**: Step-track algorithm finds and maintains signal peak

5. **Continuous Tracking**: Step-track follows satellite throughout pass

</Steps>

<Aside type="tip">
**Why Start with Program-Track?**

Program-track gets you close enough to detect the beacon. Without an initial pointing estimate, step-track would have to search the entire sky. Program-track provides the starting point; step-track provides the precision.
</Aside>

## Beacon Tracking Fundamentals

### What is a Satellite Beacon?

Satellites transmit continuous reference signals called beacons. These serve multiple purposes:

**For Ground Stations:**
- Antenna tracking reference (step-track)
- Frequency reference for calibration
- Power monitoring for link budget verification
- Satellite health indicator

**Beacon Characteristics:**
- **Continuous Wave (CW)**: Pure tone, very narrow bandwidth
- **Stable frequency**: Typically within a few Hz of nominal
- **Known power**: Published in satellite documentation
- **Always on**: Transmitting regardless of traffic load

### AURORA-7 Beacon Configuration

| Parameter | Value | Notes |

**IF Calculation:**
```
IF = LO - RF
IF = 5,250 MHz - 4,165 MHz
IF = 1,085 MHz
```

Charlie has already configured the beacon receiver to 1,085 MHz IF. When you enable step-track, the ACU will monitor this beacon to optimize antenna pointing.

## Frequency Conversion Review

### The LNB: Receive Chain Downconversion

The Low Noise Block downconverter (LNB) translates satellite signals from RF to IF:

**C-Band Configuration (High-Side LO):**
```
IF = LO - RF
```

| Signal | RF Frequency | IF Frequency |
|--------|-------------|--------------|
| Beacon | 4,165 MHz | 1,085 MHz |
| Downlink | 3,605 MHz | 1,645 MHz |

### The BUC: Transmit Chain Upconversion

The Block Upconverter (BUC) translates transmit signals from IF to RF:

**C-Band Configuration (Low-Side LO):**
```
RF = IF + LO
```

Therefore:
```
IF = RF - LO
```

| Signal | RF Frequency | IF Frequency |
|--------|-------------|--------------|
| Uplink | 5,830 MHz | 905 MHz |

<Aside type="caution">
**TX IF Calculation**

You'll need to calculate the transmit IF frequency in this scenario. Remember:
- Uplink RF: 5,830 MHz
- BUC LO: 4,925 MHz
- TX IF = RF - LO = 5,830 - 4,925 = 905 MHz

This is different from downlink calculation because the BUC uses low-side injection for upconversion.
</Aside>

## Security: Encryption Awareness

### Why Encryption Matters

Satellite links traverse open sky - anyone with appropriate equipment can receive transmissions. Encryption protects:

- **Confidentiality**: Content cannot be read by eavesdroppers
- **Integrity**: Tampering can be detected
- **Authentication**: Parties can verify each other's identity

### AES-256-GCM

The encryption configuration for AURORA-7 uses AES-256-GCM:

**AES-256:**
- Advanced Encryption Standard
- 256-bit key length
- Symmetric encryption (same key for encrypt/decrypt)
- Approved for classified information

**GCM (Galois/Counter Mode):**
- Authenticated encryption
- Provides both confidentiality and integrity
- Detects if ciphertext has been modified
- High performance with hardware acceleration

### Verification Before Transmission

Before enabling the transmit path, always verify:

1. **Encryption Status**: Is encryption enabled?
2. **Key Status**: Is the key valid (not expired)?
3. **Algorithm**: Is the correct algorithm configured?

Never transmit sensitive traffic without verifying encryption is active.
