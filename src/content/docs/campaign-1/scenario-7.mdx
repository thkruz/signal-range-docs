## Background: Post-Maintenance Validation

### Why Validate After Maintenance?

Any time equipment is touched - replaced, adjusted, inspected, or reconfigured - you must verify it works correctly before returning to service. This is especially critical for transmit equipment because:

**Risk of Interference:**
- Incorrect frequency configuration transmits on the wrong channel
- Excessive power violates coordination agreements
- Misconfigured modulation corrupts the signal

**Risk of Equipment Damage:**
- Mismatched impedances cause reflected power
- Overdriven amplifiers generate excessive heat
- Improper sequencing damages components

**Professional Standards:**
- SOPs require documented validation
- Regulatory compliance demands verification
- Customer SLAs expect error-free service restoration

### The Validation Sequence

Post-maintenance validation follows a specific order:

<Steps>

1. **Check for Alarms**: Review Dashboard for any active fault conditions

2. **Verify RX Chain**: Confirm antenna, LNB, and beacon reception are operational

3. **Configure TX Modem**: Set correct IF frequency, bandwidth, modulation, and power

4. **Loopback Test**: Use BUC loopback to verify TX signal path without transmitting

5. **Enable HPA**: Power on the High Power Amplifier

6. **Verify Encryption**: Confirm link security before transmission

7. **Go Live**: Unmute BUC to begin transmission

8. **Monitor Power**: Verify HPA output is within limits

</Steps>

## Understanding BUC Loopback

### What is Loopback Mode?

The Block Upconverter (BUC) includes a loopback function that routes the TX IF signal back to the receive chain instead of upconverting to RF and sending it to the antenna.

**Signal Path - Normal Mode:**
```
TX Modem → BUC → Upconvert to RF → HPA → Antenna → Satellite
```

**Signal Path - Loopback Mode:**
```
TX Modem → BUC → Internal Loop → Receive Chain → Spectrum Analyzer
```

### Why Use Loopback?

Loopback testing validates the low-power transmit chain (modem and BUC) without:

- Engaging the High Power Amplifier
- Transmitting RF through the antenna
- Risk of interference to the satellite
- Risk of coordination violations

**What Loopback Verifies:**
- TX modem is generating the correct signal
- BUC is receiving and processing the IF
- Signal path from modem to BUC is intact
- Frequency, bandwidth, and modulation are correct

**What Loopback Does NOT Verify:**
- HPA operation
- Waveguide path to antenna
- Antenna transmission
- Satellite transponder response

<Aside type="caution">
**Loopback Before Live**

Never bring an uplink online after maintenance without first performing a loopback test. Catching configuration errors at low power is far better than discovering them after you've transmitted an out-of-spec signal toward the satellite.
</Aside>

## TX IF Frequency Calculation

### BUC Upconversion

The BUC translates transmit signals from IF to RF using low-side injection:

**Formula:**
```
RF = IF + LO
```

Therefore, to find the required IF:
```
IF = RF - LO
```

### TIDEMARK-1 Uplink Calculation

| Parameter | Value |
|-----------|-------|
| Target RF | 5,943 MHz (TP-1 center) |
| BUC LO | 4,900 MHz |
| Required IF | ? |

**Calculation:**
```
TX IF = RF - BUC LO
TX IF = 5,943 MHz - 4,900 MHz
TX IF = 1,043 MHz
```

<Aside type="tip">
**TX vs RX Calculation**

Note the difference from receive calculations:
- **RX (LNB)**: IF = LO - RF (high-side injection, subtractive)
- **TX (BUC)**: IF = RF - LO (low-side injection, subtractive from target)

Both subtract, but the operand order is different.
</Aside>

### BUC Over-Temperature Condition

The BUC is showing an over-temperature warning at startup:

**Symptoms:**
- Temperature: 75°C (threshold is 70°C)
- Alarm: Over-temperature warning on Dashboard

**Root Cause:**
- BUC gain set to 35 dB (too high)
- Maintenance crew left elevated gain from testing
- High gain = higher power dissipation = more heat

**Resolution:**
- Reduce BUC gain to normal operating level (~25 dB)
- Temperature will drop as power dissipation decreases
- Verify alarm clears on Dashboard before proceeding

## Link Security

### Encryption Requirements

TIDEMARK-1 service agreements require AES-256 encryption on all uplink traffic. Before transmitting, you must verify:

**Encryption Card Status:**
- Mode: ACTIVE (not BYPASS)
- Algorithm: AES-256
- Key Status: Valid (not expired)

**Why This Matters:**

Satellite links are inherently broadcast - anyone with a dish pointed at the satellite can receive the downlink. Encryption ensures:

- **Confidentiality**: Only authorized receivers can decode content
- **Integrity**: Tampering can be detected
- **Compliance**: Meets contractual and regulatory requirements

<Aside type="danger">
**Never Transmit Without Verification**

Transmitting unencrypted traffic when encryption is required is a serious breach. Always check the Encryption card status before enabling transmission.
</Aside>

## HPA Enable Sequence

### High Power Amplifier Safety

The HPA (High Power Amplifier) amplifies the BUC output to levels suitable for satellite transmission - typically 100+ watts. This power level requires careful handling:

**HPA Sequencing Rules:**

1. **Power On First**: Enable HPA power before RF path
2. **Verify Ready**: Check HPA status shows ready
3. **Enable Output**: Activate RF output stage
4. **Check Backoff**: Verify operating point is within linear region
5. **Then Unmute BUC**: Only after HPA is ready

**Why This Order?**

- HPA needs time to warm up and stabilize
- Driving an unpowered HPA can damage input circuits
- Proper sequencing protects expensive equipment

### HPA Operating Parameters

| Parameter | Target | Why |
|-----------|--------|-----|
| Output Power | >100 W | Meet link budget |
| Backoff | ~3 dB | Stay in linear region |
| Temperature | Normal | Avoid thermal shutdown |

**What is Backoff?**

Backoff is how far below maximum power the HPA operates:

```
Backoff (dB) = Maximum Power (dBW) - Operating Power (dBW)
```

Operating with backoff (~3 dB) keeps the amplifier in its linear region, preventing:
- Signal distortion from compression
- Spectral regrowth into adjacent channels
- Intermodulation products

    Ensure temperature stays below 70°C threshold.
