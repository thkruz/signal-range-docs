## Restoration Sequence

The standard restoration order — reverse of shutdown — is RX before TX, low-power before high-power. Power up only after you've inspected each panel's current state.

### Receive Path

1. Repoint antenna to TIDEMARK-1 (program-track)
2. Power up LNB → wait for thermal stability + reference lock
3. Tune spectrum analyzer to the TM-1 beacon IF
4. Verify RX modem regains lock with healthy C/N margin

### Transmit Path

1. Inspect TX chain panel — identify anything outside the operating baseline
2. Power up BUC → confirm reference lock (BUC stays muted from the safed state)
3. Correct the maintenance leftover — BUC gain back to 23 dB (powered + muted = safe to adjust)
4. Power up HPA → output stays disabled
5. Enable TX modem transmit — the modem drives into a muted BUC
6. **Stop there.** The chain stays staged cold until the handover return

<Aside type="caution">
Do not unmute the BUC or enable the HPA output before the handover executes.
Maine is still radiating at TIDEMARK-1 — a second uplink on the same
transponder is dual illumination and an immediate mission failure. The
transfer stands Maine down and brings Vermont up in one coordinated swap.
</Aside>

## Handover Return Coordination

### Catherine's Constraints

Catherine has been holding TM-1 since the maintenance window opened. She's not under any time pressure but a clean planned handover is the grade.

**Pre-release criteria for VT-01 — confirm all before requesting traffic back:**

- [ ] Antenna locked on TIDEMARK-1 in program-track
- [ ] LNB powered, reference locked, thermally stable
- [ ] Spectrum analyzer shows TM-1 beacon at 1,074.5 MHz IF
- [ ] RX modem locked with C/N ≥ 10 dB
- [ ] BUC powered, reference locked, gain at operating value — muted
- [ ] HPA powered, output disabled (staged)
- [ ] TX modem transmitting (into the muted BUC)

Anything short of all of the above is reason to stay on Maine until the gap is closed.

### Executing the Return

Select TIDEMARK-1 in the asset tree from the Maine console, set VT-01 as the handover target, and execute. The traffic control manager coordinates the BUC/HPA state on both ends — Catherine's uplink stands down as yours comes up.
