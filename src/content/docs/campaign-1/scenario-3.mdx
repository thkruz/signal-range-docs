## Weather Handover Procedure (SOP-WX-003)

Operations rolled out this procedure last month after the January ice storm revealed gaps in our ad-hoc approach. This is the first time VT-01 has needed to execute it.

<Aside type="caution">
Maine's look angles differ from Vermont's. Program Track calculates correct pointing automatically - never manually enter Vermont's coordinates at Maine.
</Aside>

### Pre-Handover: Protect Vermont

- [ ] Enable feed heater on Vermont ACU
- [ ] Note current AGC compensation level

### Backup Site Activation (Maine)

**Timing Verification**
- [ ] GPSDO locked
- [ ] GNSS signal present

**Antenna**
- [ ] Tracking mode: Program Track (PROGRAM)
- [ ] Target: TIDEMARK-1, then press Move to Target
- [ ] Position reached

**Receive Chain**
- [ ] LNB powered, LO: 5,250 MHz, Gain: 60 dB
- [ ] LNB ready: LOCK shows LOCKED, noise temperature under 100 K, Thermal reads Stable (a cold LNB warms up for about 90 s after power-on)
- [ ] Spectrum analyzer: Center 1,074.5 MHz, Span 0.002 MHz (2 kHz; the span field is in MHz), Min Amp -65 dBm, Max Amp -50 dBm
- [ ] Beacon visible at 1,074.5 MHz IF

**Receiver (Modem)**
- [ ] Frequency: 1,532 MHz
- [ ] Bandwidth: 36 MHz, Mod: QPSK, FEC: 3/4
- [ ] Carrier lock confirmed
- [ ] C/N ≥ 10 dB

**Transmitter (Modem)**
- [ ] Frequency: 1,057 MHz, Power: -7 dBm
- [ ] Bandwidth: 36 MHz, Mod: QPSK, FEC: 3/4
- [ ] Transmission enabled

### Traffic Transfer

- [ ] Open TIDEMARK-1 satellite dashboard
- [ ] Execute transfer: VT-01 → ME-02
- [ ] Verify service continuity (zero packet loss target)

### Post-Handover: Stow Vermont

- [ ] Return to Vermont station view
- [ ] Set tracking mode: Stow (click STOW, then APPLY on the Antenna Positioning card)
- [ ] Confirm antenna reaches stow position (El: 90°)

### Handover Log Entry

Type the handover into the Ops Log (station sidebar) before you sign off. Every weather handover gets an entry, even a clean one:

- Time the weather started degrading the link, and time the handover completed
- Satellite and services affected (TIDEMARK-1, enterprise data)
- Stations involved (VT-01 to ME-02)
- Weather conditions at the primary site
- Anything abnormal you saw during the transfer

The log is what post-incident review and seasonal pattern analysis run on.
