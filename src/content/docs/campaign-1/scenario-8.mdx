## Background: The Solo Night Shift

### Why Night Shifts Matter

Satellite ground stations operate 24/7. Night shifts are typically quieter, but when problems occur, fewer people are available to help. Solo night operators must:

- **Self-triage**: Determine severity without second opinions
- **Diagnose independently**: No senior operator watching over shoulder
- **Make escalation decisions**: Know when to wake on-call staff vs. handle alone
- **Document thoroughly**: Day shift needs to know what happened

### AURORA-7 Characteristics

AURORA-7 is a legacy satellite you encountered in Scenario 6:

| Parameter | Value | Notes |
|-----------|-------|-------|
| Orbit Type | Inclined GEO | Stopped N-S station-keeping |
| Beacon RF | 4,165 MHz | C-band |
| Beacon IF | 1,085 MHz | With 5,250 MHz LNB LO |
| Uplink RF | 5,830 MHz | C-band |

**Key Challenge:** AURORA-7's inclined orbit means it drifts in a figure-8 pattern. Program-track cannot compensate for this drift - step-track is required for reliable tracking.

## Initial Equipment Status

### Vermont Ground Station (VT-01) at 2:17 AM

| Equipment | Status | Issue |
|-----------|--------|-------|
| Antenna | Program-track on AURORA-7 | **Wrong mode for inclined orbit** |
| GPSDO | Locked, operational | OK |
| LNB | Powered, **reference unlocked** | **Fault - needs diagnosis** |
| BUC | Powered, muted, 4,925 MHz LO | OK |
| HPA | Powered, disabled | Ready for enable sequence |
| Spectrum Analyzer | 1,000 MHz center | Needs reconfiguration |

### Fault Conditions Present

**LNB Reference Unlock:**
- The LNB shows "reference unlocked" status
- The GPSDO is operational (locked to GPS)
- This indicates the LNB is not receiving or cannot lock to the 10 MHz reference
- Common fix: Power cycle the LNB to force re-acquisition

**Tracking Mode Mismatch:**
- Antenna is in program-track mode
- AURORA-7 has an inclined orbit
- Program-track predictions cannot follow orbital drift
- Step-track is required for reliable tracking

## Frequency Calculations Reference

### AURORA-7 Beacon (Receive)

| Parameter | Value |
|-----------|-------|
| Beacon RF | 4,165 MHz |
| LNB LO | 5,250 MHz |
| Beacon IF | 1,085 MHz |

**Calculation:**
```
IF = LO - RF
IF = 5,250 - 4,165
IF = 1,085 MHz
```

### AURORA-7 Uplink (Transmit)

| Parameter | Value |
|-----------|-------|
| Uplink RF | 5,830 MHz |
| BUC LO | 4,925 MHz |
| TX IF | 905 MHz |

**Calculation:**
```
IF = RF - LO
IF = 5,830 - 4,925
IF = 905 MHz
```

<Aside type="tip">
**Remember the Formulas**

- **Receive (LNB)**: IF = LO - RF (high-side injection)
- **Transmit (BUC)**: IF = RF - LO (low-side injection)

Both subtract, but the operand order differs.
</Aside>

## Troubleshooting Approach

### Systematic Problem Solving

When faced with "intermittent connectivity," work through the signal chain:

**1. Timing Reference**
- Is GPSDO locked?
- Are all devices receiving 10 MHz reference?

**2. Receive Chain**
- Is LNB powered and locked?
- Is antenna pointing correctly?
- Is beacon visible on spectrum analyzer?

**3. Tracking**
- What tracking mode is active?
- Is it appropriate for this satellite?
- Is beacon lock achieved?

**4. Transmit Chain (if bidirectional)**
- Is TX modem configured correctly?
- Does loopback test pass?
- Is HPA enabled and not overdriven?

### The Diagnostic Mindset

Don't assume. Verify.

- **Check the Dashboard first** - alarms tell you where to look
- **Verify the timing source** - GPSDO is the foundation
- **Follow the signal chain** - systematic is faster than guessing
- **Use loopback testing** - validate before radiating
