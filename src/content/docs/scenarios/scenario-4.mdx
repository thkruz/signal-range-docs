### RF to IF Conversion - The Mathematics

<Aside type="tip">
**Key Concept: Frequency Downconversion**

The LNB (Low Noise Block) downconverts high-frequency RF signals from the satellite to a lower Intermediate Frequency (IF) that equipment can process. This is done by mixing the RF input with a Local Oscillator (LO).
</Aside>

**Basic Downconversion Formula:**

```
IF = RF_input - LO
```

Where:
- **IF**: Intermediate Frequency (what you want to get)
- **RF_input**: Radio Frequency from satellite (what you're receiving)
- **LO**: Local Oscillator frequency (what you must calculate)

**To Calculate Required LO:**

```
LO = RF_input - IF_target
```

**For This Mission:**

Given:
- RF_input (beacon) = 3,947.8 MHz
- IF_target (standard) = 1,247.5 MHz

Calculate:
- LO = ?

**Your Task:**
Calculate the LO frequency and enter it when configuring the LNB. Charlie will verify your calculation before you execute.

### Filter Selection Guide

**Available IF Filters:**
1. **100 kHz** - Wide bandwidth for broadband signals
2. **36 MHz** - Very wide for transponder monitoring
3. **10 kHz** - Narrow for CW carriers and beacons
4. **5 MHz** - Medium for typical data carriers

**Selection Criteria:**

For a **CW (Continuous Wave) Beacon**:
- Signal bandwidth: ~1 kHz (very narrow, unmodulated carrier)
- Best filter: **10 kHz** (narrow enough to reduce noise, wide enough for beacon)
- Rationale: Narrower filter = less noise = better signal-to-noise ratio

For a **Data Carrier (5 MHz symbol rate)**:
- Signal bandwidth: ~5 MHz
- Best filter: **5 MHz** or wider
- Rationale: Filter must pass entire signal bandwidth

**Your Task:**
Select the appropriate filter for acquiring the CW beacon.

### Spectrum Analyzer Configuration

**Parameters You Must Set:**

1. **Center Frequency**: Where to look for the signal
   - Should match your target IF frequency
   - For this mission: 1,247.5 MHz

2. **Span**: How wide a frequency range to display
   - For CW beacon: Narrow span (1-10 kHz range)
   - Allows detailed view of narrow signal

3. **RBW (Resolution Bandwidth)**: Frequency resolution
   - For CW beacon: Very narrow (10-100 Hz)
   - Determines ability to resolve narrow signals
   - Narrower RBW = better for CW carriers

4. **Reference Level**: Top of display amplitude scale
   - Should be near expected signal level
   - For this beacon: -85 to -90 dBm range
   - Allows signal to be visible on screen

**Your Task:**
Configure all four parameters appropriately for a CW beacon at IF.

### RF Fundamentals Review

**Why Do We Downconvert?**

Satellite signals arrive at high RF frequencies (3.7-4.2 GHz for C-band downlink). Most signal processing equipment works better at lower intermediate frequencies (950-1450 MHz IF). The LNB performs this frequency translation.

**Mixer Operation:**
The LNB contains a mixer that combines:
1. **RF input** (from satellite via antenna)
2. **Local Oscillator** (generated internally)

The mixer produces multiple output frequencies:
- RF + LO (sum frequency - filtered out)
- **RF - LO** (difference frequency - this is our IF!)
- Various harmonics (filtered out)

**Image Frequency:**
There's actually two RF frequencies that can produce the same IF:
- RF = LO + IF (upper sideband)
- RF = LO - IF (lower sideband)

The LNB's input filter rejects the unwanted image frequency, so we only get the desired conversion.

### Common Calculation Errors

**Mistake 1: Wrong Formula**
```
WRONG: LO = RF + IF
WRONG: LO = IF - RF
RIGHT: LO = RF - IF
```

**Mistake 2: Unit Confusion**
```
WRONG: LO = 3947.8 - 1.2475 = 3946.5525 (mixing MHz and GHz)
RIGHT: LO = 3947.8 - 1247.5 = 2700.3 (consistent MHz units)
```

**Mistake 3: Decimal Errors**
```
WRONG: LO = 3947.8 - 1247.5 = 270.3 (missing digit)
WRONG: LO = 3947.8 - 1247.5 = 27003 (wrong decimal place)
RIGHT: LO = 3947.8 - 1247.5 = 2700.3
```

**Mistake 4: Rounding Too Early**
```
POOR:  LO = 3948 - 1248 = 2700 (rounded inputs)
GOOD:  LO = 3947.8 - 1247.5 = 2700.3 (precise calculation)
```

### Filter Selection Logic

**Signal Type → Filter Choice:**

| Signal Type | Bandwidth | Recommended Filter |
|------------|-----------|-------------------|
| CW Beacon | ~1 kHz | 10 kHz |
| QPSK 2 Msps | ~2 MHz | 5 MHz |
| 16APSK 5 Msps | ~5 MHz | 5 MHz |
| Transponder Monitor | 36 MHz | 36 MHz |

**Rule of Thumb:**
Filter bandwidth should be 2-5× the signal bandwidth for adequate margin while minimizing noise.

### Spectrum Analyzer Settings Logic

**For CW Beacon Acquisition:**

| Parameter | Value | Reason |
|-----------|-------|--------|
| Center Freq | Target IF (1247.5 MHz) | Where signal should appear |
| Span | 1-10 kHz | Narrow view of CW signal |
| RBW | 10-100 Hz | Resolve narrow carrier |
| Reference Level | Expected + 5 dB | Position signal on screen |

**Effect of RBW:**
- Narrower RBW: Better frequency resolution, slower sweep, better for CW
- Wider RBW: Faster sweep, better for wide signals, worse for CW
