| Zeroize control | Armed-then-fire; **not part of a rotation** |

<Aside type="danger">
Zeroize destroys the key material on the console. It is an emergency control with its own arming switch for a reason. A zeroized station cannot command anything until re-keyed by Rotterdam, and that does not happen inside a seven-minute pass.
</Aside>

## Uplink Plan

BUC is low-side injection: **RF = IF + LO** (12,600 MHz LO). LNB is high-side: **IF = LO − RF** (13,100 MHz LO).

| Path | IF (MHz) | RF (MHz) | Format |
|------|----------|----------|--------|
| SAR-1 telecommand uplink | 1,405 | 14,005 | QPSK 3/4, 36 MHz, −7 dBm modem |
| SAR-1 telemetry beacon (down) | 1,389 | 11,711 | CW |
| SAR-1 imagery downlink | 1,414 | 11,686 | QPSK 3/4, 36 MHz |

Uplink Doppler is still ±325 kHz and compensation is still required for an ACK. Yesterday's lesson does not switch off because today's arrived.

## End of Briefing

A command link anyone can use is not a command link. The authentication tag is the only thing standing between MERIDIAN and whoever else can point a dish at it, and the rotation schedule is what keeps that tag worth something.

The payload has to be safed before the imaging block. Anneke is not going to get another window from us today, and she knows it.
