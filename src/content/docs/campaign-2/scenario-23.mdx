## The Surge

At 21:14, inside a minute:

| What | Where you see it | What it costs |
|------|------------------|---------------|
| GNSS spoof | GPS Timing: ΔT walking, constellation healthy | Timestamps. Nothing on the pass |
| SAR-2 debris-avoidance burn | Pass Schedule: **EPHEMERIS STALE** against SAR-2 | **The pass.** Program-track points where the bird was |
| Jammer expected in the window | Nowhere yet - the carrier is clear | Nothing, until it is on the air |

Three things, eight minutes, one command. None of them is a fault on the station. Each has a ten-second answer. The whole exam is the order.

<Aside type="caution">
Rank by what loses the pass, not by what alarmed first. A stale element set loses it outright: at 660 km, a few seconds along-track is a beamwidth, and program-track does not search. A walking reference costs a microsecond a second in timestamps and can wait four minutes. A jammer that is not on the air costs nothing until it is - and a hop set spent on a forecast is a hop set gone.
</Aside>

## The Order

| Step | Where | Time it takes |

| 1. Load Updated Ephemeris (SAR2-DAM) | Pass Schedule inbox | One click; the slew is immediate |

| 3. Nothing | Security console | The key stays in the store until a denial is called |

Then the pass as normal: pre-position on 022°, program-track on the post-burn set, chain up at 21:22:21, HK-DUMP on the fixed carrier. The ACK proves the holdover: a free-running OCXO is a perfectly good 10 MHz for Doppler compensation, the modem clock and the BUC LO. Only the timestamps carry the offset.

## The Denial

From 21:24:30 PLD-SAFE comes back **Uplink denied - carrier jammed**. Key Valid, Doppler engaged, window OPEN, reference in holdover.

| Suspect | Why it is not |
|---------|---------------|
| The holdover reference | HK-DUMP ACKed on it four minutes earlier; an OCXO drifts nanoseconds an hour. Putting GNSS back hands the reference to the spoofer again |
| The key | Valid at both ends; a key rejection is its own reason on the console |
| Standing down | Shetland has no command key; the payload has no next window |

The answer is the one it was on the 16th, with everything else still broken around it: call it, Anneke keys SAR-2, Load Hop-Set Key, Frequency hopping, **SYNC LOCKED**, resend. PLD-SAFE goes up on a set they did not control, a reference they could not reach and a sequence they did not have.

<Aside type="note">
Two hop sets spent on the same carrier in eight days is a pattern. The response is still a called hop - but HOP-SAR2-06 is staged closer, the switch is expected on the first NAK, and it is written into the pre-pass sweep. Hopping from AOS burns a set on every pass that is not denied.
</Aside>
