Decode windows (C/N ≥ 8 dB): SAR-1 about 14:05 to 14:08:30, peak ~11 dB at culmination; SAR-2 on current elements about 14:20:45 to 14:23:40, peak ~10 dB.

### What stale looks like

| Elements | Pedestal | Carrier on RX analysis |
|----------|----------|------------------------|
| Current | LOCKED | Rises with elevation: about 4 dB at 10°, 7 dB at 14°, 10 dB at the top |
| Stale (post-burn, old set) | **LOCKED** | Present but weak, peaks around 4 dB at 12° and then **falls as the bird climbs**, to below zero at culmination |

A fixed along-track error is a bigger angle at shorter range: 3.5 km is 0.1° at 2,000 km and 0.25° at 828 km. The closer the bird, the worse the miss. Program-track lock means the pedestal is where it was told to go; it does not mean it was told right.

<Aside type="caution">
Program-track on a stale set does not fail loudly. The pedestal slews smoothly to where the old orbit says the bird is and holds there with every drive indicator green. Look at the carrier, not the pedestal. If C/N is falling while elevation is rising, check the ephemeris panel before you check anything else.
</Aside>

## Element Sets

| Set | Epoch | Describes |
|-----|-------|-----------|
| SAR-2, on file at turnover | 2027-03-15 14:00Z | The orbit before the burn |
| SAR-2, post-burn distribution | 2027-03-15 14:11:30Z | The orbit after it |

An element set is a snapshot of the orbit at its epoch. Anything the spacecraft does after that instant is invisible to it. Two clocks run on every set: the calendar, which erodes it slowly (drag and model error grow the along-track error by hundreds of metres a day at 360 km), and the thruster, which breaks it at once. Rotterdam distributes fresh elements every few days for the first reason and within minutes for the second.

### Pass Schedule Ephemeris Panel Reference

| Display | Meaning |
|---------|---------|
| NOMINAL | No manoeuvre notice; the loaded set is the current distribution |
| EPHEMERIS STALE | A manoeuvre notice has been received for this spacecraft and the loaded elements pre-date it |
| Load Updated Ephemeris | Replaces the element set with the post-manoeuvre distribution; predictions and program-track update immediately |
| UPDATED | Current elements loaded; pass predictions and pointing are trustworthy again |

## Link Parameters

LNB is high-side injection: **IF = LO − RF** (13,100 MHz LO).

| Signal | RF (MHz) | IF (MHz) | Format |
|--------|----------|----------|--------|
| SAR-1 imagery downlink | 11,686 | 1,414 | QPSK 3/4, 36 MHz |
| SAR-1 telemetry beacon | 11,711 | 1,389 | CW |
| SAR-2 imagery downlink | 11,730 | 1,370 | QPSK 3/4, 36 MHz |
| SAR-2 telemetry beacon | 11,703 | 1,397 | CW |

The Doppler profile changes by a negligible amount for a burn this size; the receiver frequency plan is unchanged. A clean reacquisition is the carrier on RX analysis, the modem locked on 1,370 MHz, and C/N at or above 8 dB through what is left of the high-elevation segment.
