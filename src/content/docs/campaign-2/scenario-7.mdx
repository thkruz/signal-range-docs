<Aside type="caution">
Program-track on a stale set does not fail loudly. The pedestal will slew smoothly to where the old orbit says the bird is and hold there with every indicator green. The beacon simply never appears. If SAR-1 does not come up on RX analysis at AOS, check the ephemeris panel before you check anything else.
</Aside>

## Link Parameters

LNB is high-side injection: **IF = LO − RF** (13,100 MHz LO).

| Signal | RF (MHz) | IF (MHz) | Format |
|--------|----------|----------|--------|
| SAR-1 imagery downlink | 11,686 | 1,414 | QPSK 3/4, 36 MHz |
| SAR-1 telemetry beacon | 11,711 | 1,389 | CW |
| SAR-2 imagery downlink | 11,730 | 1,370 | QPSK 3/4, 36 MHz |
| SAR-2 telemetry beacon | 11,703 | 1,397 | CW |

The Doppler profile changes by a negligible amount for a burn this size; the receiver frequency plan is unchanged. A clean reacquisition is the beacon on RX analysis, the modem locked on 1,414 MHz, and C/N at or above 8 dB through the high-elevation segment (roughly 14:05 to 14:08).
