<Aside type="caution">
A LEO spacecraft covers about 7.5 km every second. On a 0.45° beam at 700 km, 20 s along-track is several beamwidths, and two degrees of mean anomaly is 250 km. Program-track on the injection set slews smoothly and holds with every indicator green, and the beam is nowhere near her. The flight rule is that a new spacecraft is not acquired on a set you know is stale: refined elements before AOS. The station's prediction and the spacecraft's orbit are separate things; only Load Updated Ephemeris joins them.
</Aside>

Which matters more, the age of a set or its origin? Origin. The injection set is a fit to no observations; it is what the rocket said it did. The refined set is fitted to ranging. Age grows the along-track error of whichever set you hold, which is why the refined set is replaced again after this pass.

## SAR-3 Frequency Plan

### The beacon on the analyzer

Downlink Doppler runs to about ±270 kHz across the pass. With the high-side LO the IF spectrum is inverted: an approaching bird (RF shifted up) lands **below** 1,315 at IF, and the tone slides **upward** as the range rate falls toward culmination, through 1,315 at the top, and on above it as she recedes. A tone on the wrong side sliding the wrong way is not your bird.

| Setting | Search | After the find |
|---------|--------|----------------|
| Centre | 1,315 MHz | 1,315 MHz |
| Span | **2 MHz** (the whole Doppler walk on screen, tone clear of the floor) | 2 MHz |
| RBW | Auto | **10 kHz** (the CW line is a line; read the slide) |

At the station's 60 MHz / 1 MHz RBW default a CW tone is one pixel above a 1 MHz noise bin, and 1,315 is not on the screen at all. Span decides what you can see; RBW decides how well.

Rotterdam wants the beacon level as a number near culmination, not "present". A level against the link prediction is the transmitter's health, and today's number is the baseline every later pass is compared with. Expect the beacon comfortably above **−65 dBm** at the analyzer input up high.

## End of Briefing

On a new spacecraft every first is evidence. The first beacon, the first lock, the first level, the first Doppler curve: each one either matches the model or it does not, and if something is sent before those are on record then a rejected command explains nothing.
