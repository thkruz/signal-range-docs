<Aside type="caution">
A LEO spacecraft covers about 7.5 km every second. On a 0.45° beam at 700 km, 20 s along-track is several beamwidths. Program-track on the injection set will slew smoothly and hold with every indicator green; the beacon is the only thing that tells you whether it is pointed at her. The flight rule is that a new spacecraft is not acquired on a set you know is stale: refined elements before AOS, or the SOH call carries a qualifier.
</Aside>

## SAR-3 Frequency Plan

LNB high-side: **IF = LO − RF** (13,100 MHz). BUC low-side: **RF = IF + LO** (12,600 MHz). SAR-3 does not share SAR-1's numbers, and the station boots on SAR-1's numbers.

| Signal | RF (MHz) | IF (MHz) | Format | This pass |
|--------|----------|----------|--------|-----------|
| SAR-3 telemetry beacon | 11,785 | 1,315 | CW, 0 dBm | Acquire and lock |
| SAR-3 imagery downlink | 11,760 | 1,340 | QPSK 3/4, 36 MHz, 28 dBm | Recorded on the TRR; not decoded |
| SAR-3 TT&C uplink | 14,065 | 1,465 | QPSK 3/4, 36 MHz | Cold |
| SAR-3 transponded downlink | 11,810 | 1,290 | | Not used |
| SAR-1 telemetry beacon (for contrast) | 11,711 | 1,389 | CW | What the ACU is set to now |

Downlink Doppler runs to about ±270 kHz across the pass, closing at AOS, zero at culmination, opening to LOS. Rotterdam wants that curve as part of the SOH: a beacon on frequency with the right Doppler profile is the transmitter, the reference, and the orbit confirmed in one measurement.

## End of Briefing

On a new spacecraft every first is evidence. The first beacon, the first lock, the first Doppler curve: each one either matches the model or it does not, and if something is sent before those are on record then a rejected command explains nothing.

Anneke has a room full of people waiting on one sentence from Galway. Load the elements, find her, and give them the sentence.

Good luck.
