## Acceptance Test Card GW-01-ATP-002

**Test:** MERIDIAN-SAR-1 imagery downlink, C/N at maximum elevation
**Method:** Predict from link budget; measure on the live receiver; accept if measured margin clears the demodulator threshold.

### Site Survey Inputs (as loaded on the Link Analysis console)

| Parameter | Value | Source |
|-----------|-------|--------|
| Satellite EIRP | 28 dBm | MERIDIAN payload data sheet |
| Slant range at max elevation | 761 km | Pass geometry, 28° culmination |
| Free-space path loss at 11,686 MHz | 171.4 dB | From the range above |
| GW-01 receive antenna gain | 51.8 dBi | 4 m Ku, measured at feed |
| System noise temperature | 88 K | LNB 60 K plus sky and feed contribution |
| Occupied bandwidth | 36 MHz | QPSK 3/4 imagery carrier |
| Implementation loss | 1 dB | Pointing, polarization, modem |

Reference: C/N = EIRP + G<sub>rx</sub> − FSPL − L<sub>impl</sub> − 10 log<sub>10</sub>(k · T<sub>sys</sub> · B), with k = −228.6 dBW/K/Hz. Mind the EIRP unit; the survey quotes dBm.

### Pass Criteria

| Check | Criterion |
|-------|-----------|
| Predicted C/N | Within 1.0 dB of the design figure on the card (~11 dB) |
| Demodulator threshold | 6.0 dB (QPSK 3/4) |
| Required margin at acceptance | 2.0 dB over threshold, measured live |
| Measurement point | On boresight under program-track, near culmination |

<Aside type="caution">
The Accept Link button reads the active RX modem's live C/N at the moment you press it. Press it on the shoulder of the pass and you will accept a number that does not represent the station. The useful window is roughly 14:05:10 to 14:08:20.
</Aside>
